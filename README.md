# Schiriplan

Schiedsrichter-Planung für die Basketball-Jugendabteilung der BG Nordstadt.

Zwei gleichwertige Schiedsrichter pro Spiel, zwei Ersatzplätze. Eintragen gilt sofort und
verbindlich — wer zuerst einträgt, hat den Platz. Nachrichten laufen über WhatsApp.

## Stand

Planungsphase. Der Implementierungsplan steht in [PLAN.md](PLAN.md), das Design in `design/`.

## Struktur

- `PLAN.md` — Entscheidungen, Fachregeln, Meilensteine, Review-Checkliste
- `design/` — der Handoff aus Claude Design: Mockup und Design-System „Modernist"
